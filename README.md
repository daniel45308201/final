# THE BIOMETRIC GATEWAY

**Terminal 07 // Acceso Biométrico** · GRADO 8° / ESL A2

Experiencia interactiva con temática cyberpunk/terminal, en español. Combina una pantalla de intro con título, un vídeo de inicio controlado por el usuario, un hub de navegación por pasos y controles para paisajes sonoros.

## 🔗 Visualizar la experiencia

Entra aquí para ver los comportamientos, probar la interacción y reproducir el vídeo de inicio:

**[https://daniel45308201.github.io/final/](https://daniel45308201.github.io/final/)**

En esa URL puedes experimentar la pantalla de intro, el arranque del vídeo, los botones de navegación del hub y los controles de los paisajes sonoros.

## Características

- **Título de la experiencia**: la pantalla inicial muestra el título *THE BIOMETRIC GATEWAY*.
- **Vídeo de inicio (`intro.mp4`)**: se precarga, pero no arranca solo. El usuario pulsa **ENTRAR / INICIAR EXPERIENCIA** para reproducirlo. También existe un botón **SALTAR INTRO**.
- **Paso al hub**: al terminar el vídeo (o al saltarlo) se da paso al hub/terminal existente.
- **Botones de navegación**: barra lateral con los pasos/milestones para moverse por la experiencia (`switchStep`).
- **Paisajes sonoros**: panel de audio ambiente con navegación de pistas, play/pausa, mute y volumen. Nota: aún no hay pistas de audio cargadas; el panel está listo para conectarlas.

## Cómo usar / Experiencia

1. Abre [https://daniel45308201.github.io/final/](https://daniel45308201.github.io/final/).
2. En la pantalla de intro verás el título de la experiencia.
3. Pulsa **ENTRAR / INICIAR EXPERIENCIA** para reproducir el vídeo de inicio, o **SALTAR INTRO** para ir directo al hub.
4. Al terminar (o saltar) el vídeo, usa los **botones de navegación** de la barra lateral para recorrer los pasos.
5. Usa el panel de **paisajes sonoros** para navegar entre pistas y controlar reproducción, mute y volumen.
